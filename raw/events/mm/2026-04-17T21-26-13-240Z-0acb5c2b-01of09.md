# Mnemonic Ingestion Pipeline

## Summary
The Mnemonic Ingestion Pipeline manages the transformation of raw material (chat logs, docs, research) into structured wiki entries. It utilizes a two-level filesystem layout (`raw/<source_type>/<project>/`) and a SQLite schema (v4) that supports source-type and project-based scoping for retrieval. The pipeline includes specialized importers like `import-claude.ts` for processing session logs.
