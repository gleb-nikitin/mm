  ## Importer change — upsert on EVERY sighting
                                                                                                     
  Both `scripts/import-claude.ts` and `scripts/import-codex.ts` (and Gemini if present) must now     
  upsert `import_state` for **every** JSONL encountered, regardless of whether it's imported, skipped
   (live), skipped (unchanged), or skipped (min-turns):                                              
                                                
  ```                                          
  for each candidate JSONL:
    derive: provider, external_id, project, cwd, model, last_user_snippet
    upsert import_state ON CONFLICT(source_path) DO UPDATE:                                          
      last_mtime        = excluded.last_mtime
      last_imported_at  = CURRENT_TIMESTAMP   -- always update: this means "last sighting"           
      provider          = COALESCE(excluded.provider, provider)                                      
      external_id       = COALESCE(excluded.external_id, external_id)                                
      project           = COALESCE(excluded.project, project)                                        
      cwd               = COALESCE(excluded.cwd, cwd)                                                
      model             = COALESCE(excluded.model, model)
      last_user_snippet = excluded.last_user_snippet                                                 
      min_turns_ok      = excluded.min_turns_ok                                                      
  ```                                          
                                                                                                     
  Derivation rules:                             
  - **provider**: from the importer itself (claude / codex / gemini — hardcoded per script).
  - **external_id, cwd, model**: reuse the parse logic already in that importer. Don't re-derive from
   scratch.                                                                                          
  - **project**: the `projectSlugFromCwd` helper already exists in each importer.                    
  - **last_user_snippet**: tail-read ~256KB of the JSONL, iterate lines in reverse, return the first 
  record whose content is a real user turn per that provider's shape. Truncate to ~200 chars. Strip  
  whitespace. If no user turn found in the tail, leave NULL.                                         
  - **min_turns_ok**: 1 if the session would pass `--min-turns`, 0 otherwise. Lets the dashboard     
  optionally exclude thin sessions.                                                                  
                                               
  Live-skipped files get this upsert. Unchanged files get this upsert (last_imported_at refresh even 
  though content didn't change). Min-turns-filtered files get this upsert with `min_turns_ok = 0`.   
                                               
  Performance: for a 3000-file run, the added cost is a small tail-read per live file (handful of    
  files typically) and a cheap upsert per file. Acceptable.                                          
                                               
  `--dry-run` semantics unchanged: still no DB mutations.
