# Holo UI — Design Guide

Visual direction for ac's holographic glass interface. Use this when building or modifying UI in `ui/`.

## Design Philosophy

"Fluid design" — elements materialize as floating glass panels. No window chrome, no title bars. Controls float alongside content with accent glow. It should feel like a real interface from a sci-fi film, but one that people actually work in.

## Design Principles

### Glass Panels
- Every app surface gets: `background: var(--window-bg); backdrop-filter: blur(var(--window-blur)); border: var(--window-border-w) solid var(--window-border); border-radius: var(--r); box-shadow: var(--window-shadow), inset 0 1px 0 var(--window-glow);`
- No solid backgrounds — everything is translucent over the desktop
- Settings knobs (opacity, blur, border, glow, spread) control all surfaces uniformly

### Window Controls — Shell Strip
- Floating vertical bar on the right side of every window
- Glass pill buttons: `background: var(--window-bg); color: var(--accent); filter: drop-shadow(0 0 3px var(--accent));`
- 50% opacity default, 100% on hover
- Grip dots (6 rows of 2, r=2) for drag, doubles as restore-from-minimize
- Zoom selector (magnifier icon + 1/2/3 dropdown)
- No padding on strip itself — app controls alignment

### Buttons — Two Variants
- **Ghost accent** (primary/aggressive): `border: 1px solid var(--accent); color: var(--accent); box-shadow: inset 0 0 12px rgba(122, 190, 212, 0.15);` — Send, +New, Save
- **Muted** (secondary): `border: 1px solid var(--window-border); color: var(--window-text-muted);` — Clear, Stop, Reset
- **Both hover**: `background: var(--btn-hover)` — uniform, never solid fills
- Never use solid accent background for buttons — it breaks the glass language

### Focus & Scale
- Focused window: `transform: scale(1)`, unfocused: `scale(0.8)`, 300ms ease-out
- Window open animation: `scale(0.5)` to `scale(1)` fade-in

### Dock Buttons
- 44px, transparent background, fixed 8px blur (independent of theme knobs)
- SVG icons forced to 20px via `!important` (overrides inline attributes)
- Minimize indicator: accent overlay at 15% opacity

### Typography & Hierarchy
- Monospace font throughout (`Monaco, Menlo, Consolas`)
- Weight: 700 headings, 600 bold, 400 body
- Color hierarchy: `var(--window-text)` primary, `var(--window-text-muted)` secondary, `var(--accent)` interactive

### Spacing
- 4/8px rhythm: `--sp-1` (4px) through `--sp-8` (32px)
- One radius: `--r: 8px`
- Shell body provides `--sp-2` base padding — apps add their own on top

### Markdown — Syntax Highlighting, Not Parsing
- Raw text stays as-is (copyable with MD tags)
- `#`/`##`/`###` markers dimmed, heading text sized + colored (H1 bright, H2/H3 accent)
- `**bold**` asterisks dimmed, text bright. `` `code` `` backticks dimmed, text accent
- `>` blockquote marker dimmed, text accent. `-` list markers accent bold
- `---` stays as text, gets accent bottom border
- `|` table pipes dimmed
- Search hits: purple background `rgba(163, 113, 247, 0.4)`

### Role Badges
- Fixed width `9ch` (fits "provider" etc.)
- `border: 1px solid var(--accent); color: var(--accent);`
- `to` field: `var(--window-text)`, same width, not muted

## Scaling

- Shell scale: `html { font-size: 100%|125%|150% }` — three options, default 125%
- Per-window zoom: selector in shell strip, 3 levels (smaller/default/bigger)
- Terminal zoom: direct font sizes (13/16/20px), independent from CSS scale
- Other apps: CSS `zoom` (0.8/1/1.2) relative to shell

## Themes

Two themes, switchable at runtime:
- `styles/themes/holo.css` — glass, cyan glow, frosted blur, text shadow
- `styles/themes/black.css` — solid dark, minimal blur, no text shadow

Themes only set CSS custom property values. All component styles use tokens.
