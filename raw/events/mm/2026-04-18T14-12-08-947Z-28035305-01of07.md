### Research Summary: Gemini Session Importer for Mnemonic51

I have confirmed that a Gemini session importer can be built for `mm` by parsing the JSON files stored in the Gemini CLI's temporary directory.

#### 1. Session Storage
Gemini session data is stored on disk at:
`~/.gemini/tmp/<project-slug>/chats/session-<ISO-timestamp>-<short-sid>.json`

Where `<project-slug>` matches the project names defined in `~/.gemini/projects.json` (e.g., `mm`, `ac`, `mt`).

#### 2. On-Disk Format
The format is standard JSON. Each file represents a single session.
- **Session ID**: Found in the top-level `sessionId` field.
- **Timestamps**: `startTime` and `lastUpdated` are in ISO 8601 format.
- **Messages**: Stored in the `messages` array.
- **User Turns**: `type: "user"`. Content is an array of objects, e.g., `content: [{ "text": "..." }]`.
- **Assistant Turns**: `type: "gemini"`. Content is a plain string.
- **Model**: Found in the `model` field of `type: "gemini"` messages.
- **Thoughts**: Inline within `type: "gemini"` messages as a `thoughts` array.
- **Tool Calls**: Inline within `type: "gemini"` messages as a `toolCalls` array.

#### 3. Implementation Strategy
A new script `scripts/import-gemini.ts` can be implemented following the pattern of `import-claude.ts`:
- **Source Type**: `llm_chat`.
- **Provider**: `gemini` (stored in `metadata`).
- **Flattening**: Combine user and assistant turns, stripping `toolCalls` and (optionally) `thoughts`.
- **Title**: `Gemini Session — <project-slug> — <sid-first-8>`.
- **Database**: Insert into `raw_events` and mirror into `events_fts`.
- **Deduplication**: Handled by `INSERT OR IGNORE` on `external_id` (the UUID from `sessionId`).

#### 4. Discovered Quirks
- **Inline Tools**: Unlike Claude, which uses separate turns for tool results, Gemini nests tool calls and results directly inside the assistant message. This simplifies the flattening process.
- **Directory Structure**: Sessions are pre-sorted into project-specific directories within `~/.gemini/tmp/`, making it easy to filter by project.
