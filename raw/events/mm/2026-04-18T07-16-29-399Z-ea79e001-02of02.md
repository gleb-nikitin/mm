### 1. How Search Quality is Maintained
The system uses a **"Filter-or-Federate"** logic in `src/core.ts`:
*   **With Filter**: If an agent specifies `project="other-project"`, the search **skips the general wiki** and only looks at the raw evidence for that specific project. This ensures 100% relevance and prevents "noise" from the `mm` project.
*   **Without Filter**: If no project is specified, the system searches the **Compiled Truth (Wiki)**. Since the wiki is project-agnostic, it returns the best-known facts across the whole brain.

*   **Explicit Tools**: The MCP tools (`search_brain`, `query_brain`) and the API specifically ask for `projects` as an optional array. Agents see this in the tool definition and will use it if they know which project they are working on.
