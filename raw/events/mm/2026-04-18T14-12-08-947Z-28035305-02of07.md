Gemini stores its JSON session logs in project-specific subdirectories within its `tmp` folder:
- **Root Path:** `~/.gemini/tmp/`
- **Pattern:** `~/.gemini/tmp/<project_slug>/chats/session-*.json`
- **Example:** `~/.gemini/tmp/mm/chats/session-2026-04-18T14-12-28035305.json`

### 2. Filtering for 3+ Interactions
To skip single-shot `-p` requests and short sessions, Codex should filter the `messages` array inside each JSON file:
