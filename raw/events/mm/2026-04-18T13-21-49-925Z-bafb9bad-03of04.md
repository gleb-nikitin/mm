## Design

### Schema v7: `import_state`

Add in `initDb()` alongside the existing migrations, idempotent shape:

```sql
CREATE TABLE IF NOT EXISTS import_state (
  source_path TEXT PRIMARY KEY,
  last_mtime REAL NOT NULL,         -- mtimeMs at time of successful import
  last_imported_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

Bump `schema_version` to 7. No backfill needed — absence of a row means "never imported."

### Importer behavior

Before calling `parseJsonlFile(...)` on each candidate JSONL:

1. **Settled check.** Compute `age_seconds = (Date.now() - mtimeMs) / 1000`. If `age_seconds < minAgeSeconds`, skip with counter `skipped (live)`. Default `minAgeSeconds = 300` (5 minutes). Settled sessions are treated as immutable; live ones are left for later. This is the sharp boundary: **past = DB, present = filesystem** (the dashboard will read the filesystem directly — do not build that here).

2. **Unchanged check.** Look up `import_state.last_mtime` for this `source_path`. If equal to current `mtimeMs`, skip with counter `skipped (unchanged)`. No parse, no DB cost.

3. **Otherwise, parse and import as today.** After all sessions in the file insert (regardless of how many were new-vs-duplicate), UPSERT `import_state`:

   INSERT INTO import_state (source_path, last_mtime, last_imported_at)
   VALUES (?, ?, CURRENT_TIMESTAMP)

     last_mtime = excluded.last_mtime,
