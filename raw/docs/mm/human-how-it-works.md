# Mnemonic51 — project entry

**Start here.** This file describes **Mnemonic51** (`mm`): a **local-first** knowledge system in this repo — **Bun + TypeScript**, **SQLite**, markdown **`wiki/`**, a **`raw/`** queue, optional **Ollama** embeddings, and **Gemini CLI** for ingest/query. It maps **where things live**, **how data flows**, **what to run**, **instruction `.md` files** (§2.3), and **every first-party `.ts` file** (excluding `node_modules`).

For a short README-style overview, see **[`README.md`](README.md)**. For behavior details, **`src/`** is authoritative if anything disagrees.

---

## 1. What this project is

- **Is:** A personal **brain** — markdown on disk as source of truth, **`meta/brain.db`** as index/queue/search layer, surfaces: **`brain` CLI**, **HTTP API** + **`ui/`**, **MCP** (`bun run mcp`).
- **Is not:** A hosted multi-tenant product, or a generic framework; it encodes a specific **provenance** model (timelines citing `raw/…` or `event:<id>`).

**Three things to separate mentally:**

| Layer | What it is |
|-------|------------|
| **Codebase** | `src/`, `scripts/`, `tests/`, `ui/` — the application you edit in git. |
| **Brain instance** | Under **`MT_BRAIN_ROOT`** (default cwd): `raw/`, `wiki/`, `meta/` — user content + DB; may be gitignored partly. |
| **Optional** | `.obsidian/` folders if you edit the vault in Obsidian — metadata only unless files change. |

## 3. Brain root and data model

**Brain root** = `MT_BRAIN_ROOT` if set, else **current working directory**. It must be able to hold `raw/`, `wiki/`, `meta/` (created as needed).

| Concept | Meaning |
|---------|---------|
| **`raw_entries`** | Rows mirroring files under `raw/`; **`processed`** flag; queue for **`brain process`**. |
| **`raw_events`** | Imported **session transcripts** (Claude/Codex/Gemini importers); **`external_id`** unique; searchable via **`events_fts`**. **`chunked=1`** once `scripts/chunk-events.ts` has digested a row into files under `raw/events/<project>/`. |
| **`wiki_pages`** + `wiki/*.md` | Curated pages; **Timeline** may cite a path under brain root or **`event:<external_id>`**. |
| **Claims / `claim_sources` / `claim_sources_event`** | Provenance links; **`source_count`** on pages. |
| **`import_state`** | Per-path/session sightings for **Active Agents** (`/active`, MCP `list_active_agents`). |
| **`chunks`** | Text + optional embeddings for hybrid search. |

**Invariants**

- **Session import ≠ wiki ingest:** importers fill **`raw_events`** (search/dashboard). **`chunk-events.ts`** turns rows into **`raw/events/…`** markdown ( **`chunked=1`** ); then **`index rebuild`** creates **`raw_entries`** for those files. Turning content into **`wiki/`** is **`brain process`** (or the **Librarian** flow in **`process-new.command`**), **`brain ingest-event`**, or manual edits.
- **Disk vs DB:** after editing `wiki/` or `raw/` by hand, run **`brain index rebuild`** (or a pipeline that includes it) so SQLite/FTS match files.
- **Provenance:** automated wiki updates should tie to **`raw/…`** or **`event:…`** in timelines (or CLI claims); `brain process` encodes this.

## 4. How work flows (operators)

### Two input lanes

1. **Markdown → `raw_entries`:** `brain add` / `save`, HTTP **`/add`**, `scripts/ingest-manual.ts`, or files under **`raw/`**. Duplicates by content hash. **`processed = 0`** until consumed.
2. **Agent sessions → `raw_events`:** `scripts/import-*.ts` read **`~/.claude`**, **`~/.codex`**, **`~/.gemini`** (not stored in repo). Writes **`raw_events`**, **`events_fts`**, **`import_state`**. Does **not** write session text into **`raw/`** by default.

### Ingestion chain (not one button)

1. **Import sessions (optional)** — refresh dashboard / searchable events.
2. **`bun scripts/chunk-events.ts [--project <p>]`** — digest un-chunked **`raw_events`** rows into ~12KB turn-aligned markdown chunks under **`raw/events/<project>/`**. Sets **`chunked=1`**.
3. **`brain index rebuild`** — sync `raw/` (including the new event chunks) + `wiki/` into SQLite (FTS, links, raw rows).
4. **`brain process`** — retro-link timeline citations (no LLM), then Gemini **ingest** for unprocessed **`raw_entries`**.
5. **`brain embed`** — Ollama at **`http://localhost:11434`**, model **`nomic-embed-text`**. If Ollama is down: FTS + events still work; vector arm missing.

**Ad-hoc chat → wiki (rare):** **`brain ingest-event <external_id>`** with timeline citation **`event:…`**. Prefer the chunker path above for production work.

### Day-to-day rhythm

- UI + API: **`run.command`** or **`bun run api`** (port **`MT_PORT`**, default **3000**).
- Active Agents / recent sessions: **`watch-agents.command`**.
- Drain queue + wiki updates: **`brain index rebuild`** as needed, then **`brain process`**; then **`brain embed`** after large changes.
- **Librarian shift (`process-new.command`):** imports Claude (**`--project mm`**), runs **`chunk-events --project mm`**, **`index rebuild`**, then launches **interactive Gemini** (`gemini -i=… --yolo`) with a prompt built from **`agent/roles/lib/soul-interactive.md`** + **`handoff.md`** + **`brain queue`** — drain the markdown queue (including **`raw/events/`** chunks) with wiki updates; optional **`meta/RELAUNCH_NEEDED`** loop. **Not** the old non-interactive “process + embed only” script.

## 7. Source code: every `.ts` file

### `src/api.ts`

Bun **`Bun.serve`**: DB init; static **`ui/`** (`/`, `/monitor`, `/ui/...`); markdown API: `/help`, `/active`, `/query`, `/validate`, `/stats`, `/wiki/:slug`, `/search`, `/add`; R1 JSON/SSE API: `/api/v1/sessions/active`, `/api/v1/sessions/events`, `/api/v1/cost/by-session`, `/api/v1/cost/by-message`.

### `src/brain.ts`

**Commander** CLI: `add`, `save`, `queue`, **`mark-processed`**, **`read-raw`**, **`queue-events`**, **`read-event`**, **`mark-event-processed`**, `search`, `projects`, `read`, `query`, `process`, `ingest-event`, `lint`, `doctor`, `validate`, `dream`, `embed`, `page create|update`, `index …`, `timeline …`; internal index/timeline generators and wiki/raw sync.

### `src/core.ts`

Paths, **`initDb()`** (schema **v10**: `raw_events.chunked`, etc.), **`hybridSearch`** (FTS + vectors + `events_fts`, RRF + event lane), **`queryBrain`** / **`validateClaim`**, **`addToBrain`**, **`embedBrain`**, **`runGemini`**, timeline helpers, **`renderActiveAgentsMarkdown`**, **`getStats`**, **`getProjects`**.

### `src/mcp.ts`

MCP stdio server: `search_brain`, `query_brain`, `add_to_brain`, `validate_claim`, `brain_stats`, `list_projects`, `list_active_agents`, `embed_brain`.

### `scripts/import-claude.ts` · `import-codex.ts` · `import-gemini.ts`

Walk vendor dirs; flatten sessions; insert **`raw_events`** + **`events_fts`** + **`import_state`**; dedup by **`external_id`**.

### `scripts/chunk-events.ts`

**Narrative chunker:** for **`raw_events`** with **`chunked=0`** (and usually **`processed=0`**), splits session text at turn boundaries into ~12KB chunks, writes **`raw/events/<project>/<timestamp>-<id>[-NNofMM].md`** with YAML frontmatter ( **`external_id`** ), sets **`chunked=1`**. Next **`brain index rebuild`** ingests those files as normal **`raw_entries`** (`source_type` **`events`**). Flags: `--project`, `--dry-run`, `--rechunk`, `--include-processed`.

### `scripts/ingest-manual.ts`

If **`how-mm-works.md`** exists, **`addToBrain`** as docs/mm titled “How Mnemonic51 Works”.

### `tests/behavior.test.ts`

Integration tests: schema **v10**, **`chunk-events`** / **`chunked`**, process retro-sweep, event lane search, `/active` shape, import dedup; PATH shim for `gemini`.
