# gbrain

Source: https://github.com/garrytan/gbrain
Author: Garry Tan

Personal memory engine for AI agents. Production brain powering OpenClaw and Hermes.

The 25 Skills:
Organized by `skills/RESOLVER.md`. Resolver tells the agent which skill to read for any task.

Notable Skills:
- **signal-detector**: Captures ideas + entities on every message.
- **brain-ops**: Brain-first lookup.
- **ingest/media-ingest**: Broad input support (Video, PDF, GitHub repos).
- **enrich**: Tiered enrichment for people/companies.
- **maintain/citation-fixer**: Periodic health checks and citation repair.
- **publish**: Share pages as password-protected HTML.

Search:
Hybrid search (vector + keyword + RRF fusion + multi-query expansion + 4-layer dedup).

Architecture:
CLI / MCP Server -> BrainEngine -> PGLite (embedded Postgres) or Supabase.

Knowledge Model:
Every page follows the compiled truth + timeline pattern. Above the `---`: compiled truth. Below: timeline (append-only evidence trail).
