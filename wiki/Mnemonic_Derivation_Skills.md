# Mnemonic Derivation Skills

## Summary
Derivation Skills form the action layer of Mnemonic51, transitioning it from a mere memory engine into an active project-management primitive. They automatically extract and maintain project documentation from conversations. The family includes 'derive-todos' for actions, 'derive-bugs' for defects, 'derive-decisions' for architectural choices, 'derive-corrections' for lessons learned, 'derive-friction' for pain points, and 'derive-exit-interview' for session-end self-evolution.
