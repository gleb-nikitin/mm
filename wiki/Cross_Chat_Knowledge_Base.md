# Cross-Chat Knowledge Base

## Summary
A pattern (WizRag) by [[Eugene_Gordeev|Eugene Gordeev]] for persistent, cross-platform knowledge using a single URL and markdown. The AI visits the URL, reads an instruction page (Skills as Markdown), and learns to retrieve from the KB, save new context, and build a browsable wiki. It employs semantic deduplication with a cosine distance threshold of 0.02 to prevent bloat. Key commands include Ask (retrieval), Save (write context), Validate (self-correction), Update wiki (clustering/contradiction detection), Lint wiki (health report), and Save to wiki (filing AI answers as pages).
