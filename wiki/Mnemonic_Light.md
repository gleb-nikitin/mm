# Mnemonic Light

## Summary
Mnemonic Light is the TypeScript/Bun-based track of Mnemonic51, optimized for rapid iteration and designed to be packaged as an ac plugin (Holo app). It follows a structured 7-step development roadmap (Tests, Skills, Refactor, Hygiene, Retrieval, Polish, Hardcore). The repository is organized with core logic in src/ and includes 'run.command' and 'kill.command' scripts as double-click entry points for the API and UI.
