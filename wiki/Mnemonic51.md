# Mnemonic51

## Summary
Mnemonic51 (short name mm) is a local-first, project-management primitive that transforms conversations and research into durable Markdown artifacts via LLM-mediated Skills. It operates with markdown as the source of truth, indexed by SQLite for efficient retrieval and semantic search. The system is designed to observe and evolve itself through a self-evolving loop where session outputs are ingested to refine project state. It is organized into src/ (core logic), meta/ (state/schema), and scripts/ (import handlers), following a two-track roadmap: Mnemonic Light (TS/Bun methodology) and Mnemonic Hardcore (Rust/Tabularium performance).
